# copilot-credits API (schema_version 1)

`GET /api/extensions/copilot-credits/usage` (HEAD allowed by host). The skill always
answers HTTP 200 JSON with `Cache-Control: no-store`. A non-200 from the host itself
(404 not registered, 409 not live, 502) means the extension is not serving: treat as
`unavailable`.

```
{
  "schema_version": 1,
  "status": "fresh" | "stale" | "unavailable",
  "source": "github.copilot_internal.user",
  "observed_at": "YYYY-MM-DDTHH:MM:SSZ" | null,      // when the shown snapshot was fetched; null iff unavailable
  "last_attempt_at": ISO | null,                      // last upstream attempt for the CURRENT credential
  "next_refresh_after": ISO | null,                   // no upstream call before this; earlier polls get the cache
  "error": null | {"code", "message", "http_status": int|null, "retry_after_s": int|null},
  "account": null | {"login": str|null, "plan": str|null},
  "premium": null | {
    "used_percentage": number|null,     // 100 - provider percent_remaining, unrounded (6 dp)
    "percent_remaining": number|null,   // provider value, 0..100
    "entitlement": number|null,
    "quota_remaining": number|null,
    "credits_used": number|null,        // provider counter; does NOT share the percentage denominator
    "unlimited": bool,
    "overage_permitted": bool|null,
    "token_based_billing": bool|null
  },
  "reset_at": ISO | null,               // account quota cycle reset (provider quota_reset_date_utc)
  "nominal_usd": null | {"basis": "1 credit = $0.01 consumption value; not an invoice",
                         "entitlement": number|null, "quota_remaining": number|null}
}
```

Invariants

- `status` fresh/stale ⇒ `premium`, `account` non-null and either `premium.unlimited === true`
  (then `used_percentage`/`percent_remaining` are null: show "Unlimited") or `used_percentage`
  is a finite number in [0, 100]. A missing/out-of-range provider percentage is
  `unavailable` + `unrecognized_response`; values are never clamped or invented.
- `unavailable` ⇒ `observed_at`, `account`, `premium`, `reset_at`, `nominal_usd` are null and
  `error` is non-null. `stale` ⇒ `error` non-null (why the refresh failed).
- Any other null field means unknown; never render it as 0.
- `stale` is only ever the same credential's last good snapshot, at most 24 h old.
- `nominal_usd` appears only when `token_based_billing === true`.

Error codes: `no_credential`, `credential_origin_mismatch`, `credential_unusable`,
`unauthorized` (401, drops snapshot), `forbidden` (403, drops snapshot), `not_found` (404),
`rate_limited` (429), `redirect_refused` (3xx), `http_error`, `timeout`, `network`,
`too_large`, `bad_json`, `unrecognized_response`, `credential_changed`, `pending`, `internal`.
`message` is fixed English per code; it never contains provider or exception text.
`credential_changed`: the key or base URL changed (or was removed) while a refresh was in
flight; that refresh's result is discarded, never cached, and the next poll uses the
current credential.

Timing: success cached 60 s; failure backoff 60 s; 401/403 300 s; 429 Retry-After clamped
60..900 s (default 300 s). Concurrent callers share one upstream call. Upstream budget 10 s,
enforced as a socket-level per-operation timeout with remaining-budget tightening (after
connect and before each later phase the socket timeout is lowered to what is left); DNS
resolution is not bounded by the extension, so wall time can exceed 10 s in rare cases.
Callers waiting on another caller's refresh wait at most 12 s, then get the cache
(`stale` + `pending`) or `unavailable` + `pending`.
Clients: poll no faster than 60 s; thresholds on unrounded `used_percentage` (>90 warn, >95 red).

Examples: `examples/fresh.json`, `examples/stale.json`, `examples/unavailable.json`
(generated by the tests from the synthetic fixture; regenerate with
`python3 tests/test_plugin.py --write-examples`).
